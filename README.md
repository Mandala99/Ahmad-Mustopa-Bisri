# Website Perkenalan Ta'aruf — Ahmad Mustopa Bisri

Website statis responsif menggunakan HTML, CSS, dan JavaScript biasa. Isi profil telah diperbarui berdasarkan informasi terbaru yang diberikan.

## Isi folder
- `index.html` — isi halaman dan profil.
- `style.css` — desain dan tata letak responsif.
- `script.js` — menu navigasi untuk ponsel.
- `assets/foto-profil.jpg` — tempat foto profil Anda.

## Melihat website di komputer
1. Ekstrak ZIP.
2. Buka folder `taaruf-website`.
3. Klik dua kali `index.html` untuk melihatnya di browser.

## Mengganti foto profil
Salin foto ke folder `assets` dan beri nama persis `foto-profil.jpg`. Foto belum disertakan agar Anda dapat memilih foto sendiri.

## Publikasi gratis melalui GitHub Pages
1. Masuk atau daftar di https://github.com/.
2. Buat repository baru, misalnya `perkenalan-taaruf`.
3. Unggah isi folder ini (index.html, style.css, script.js, dan folder assets), bukan file ZIP-nya.
4. Buka **Settings → Pages**.
5. Pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu simpan.
6. Tunggu proses selesai dan buka URL yang ditampilkan pada halaman Pages.

## Sebelum dipublikasikan
Pastikan Anda nyaman membagikan nama, foto, dan informasi profil. Hindari mencantumkan alamat rumah rinci, nomor identitas, informasi keuangan, atau data pribadi keluarga. Website ini tidak memiliki formulir kontak atau menyimpan data pengunjung.

## Mengedit teks
Buka `index.html` dengan Notepad atau Visual Studio Code, ubah teks yang diinginkan, lalu simpan. Pertahankan tag HTML seperti `<p>`, `<section>`, dan tag penutupnya.


## Pembaruan profil
Website ini juga memuat bagian **Harapan & Kriteria Pasangan**, berisi lima poin yang diberikan untuk membantu menjelaskan harapan dalam proses ta'aruf.
